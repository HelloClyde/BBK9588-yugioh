# 固定 SDK 与应用兼容层

- SDK：`sdk/` 子模块，公开提交 `f2fcbe020e7e94014c33d7e5c593802e4b1e3034`。
- 上游：`upstream/` 子模块，`f1e83a84d8a9dbe686bb1eef064118e409b46274`。
- 编译器：MIPS GNU GCC 15.2.0，MIPS32 little-endian、O32、soft-float。
- 游戏入口 `0x81c00020`，完整载入的静态区域必须低于 `0x81e00000`。

移植开发时 SDK 工作区还有未公开改动。本应用实际使用的新增项只有 `bda_fs_flush_all()`：它调用 C200 FS 表 `+0x074` 的全局刷写入口，随后仍按原流程关闭并重读存档校验。

公开项目把这一小段封装收录为 `src/sdk_compat9588.h`。其调用体与已经做过双槽保存、CRC、正常退出及重读验证的版本保持等价；它不是 `fflush(file)`，也不向调用者暴露固件混合返回值。

构建使用干净、固定的 SDK 子模块，不复制 SDK 未提交文件，不要求发布整个 SDK 工作区。若未来 SDK 正式提供该入口，兼容层通过公开宏检测避免重复定义；本项目仍默认固定当前提交，不自动升级。

公开 BDA 使用独立生成的几何桌面图标；游戏内图片、字体和声音仍由外部原资源加载。对照验证会分别记录完整 BDA、载入映像和 `.text` 的 SHA-256，不能用“代码相同”冒充未实际做过的整机验证。
