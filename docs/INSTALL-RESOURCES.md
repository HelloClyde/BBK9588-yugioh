# 独立资源包

这是 BBK 9588 版本的五个配套运行资源。直接解压到设备 A 盘根目录，得到 `A:\YUGIOH\FONT.BIN`、`H1UI.PAK`、`H1ART.PAK`、`H1SCN.PAK` 和 `H1SND.PAK`。

程序另从同一 Release 下载 `Yugioh9588.bda`，复制为 `A:\应用\程序\游戏王.bda`，刷新桌面后从“娱乐天地”启动。若下载的是名称以 `-full.zip` 结尾的完整安装包，其中已经包含本资源包，无需重复安装。

资源也可位于 `B:\YUGIOH\`，程序优先 A 盘。此包不含存档，不会提供或替换 `JNAT0.SAV` / `JNAT1.SAV`。资源来自固定 H1 v0.1.1 配套包，原始字节未改动；这里只把安装目录调整为 9588 使用的 `YUGIOH/`。

每个资源的大小和 SHA-256 见 `YUGIOH/resources-manifest.json`。来源与许可范围见 `SOURCE_NOTICE.md`；代码的 Apache-2.0 许可证不授予第三方资源的权利。
